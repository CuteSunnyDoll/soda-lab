# 🥤 Soda Lab (意式蘇打特調工坊 / Italian Soda DIY)

> **在家 1:1 調製名店風味意式氣泡蘇打、雪頂奶霜 (Cremosa) 與夏日特飲。**  
> 智慧動態泵數換算 • 分步驟倒計時器 • 防凝固結塊科學指南 • Amazon 原物料合規直購 • 每杯省下 $5+ 飲品錢。

## 🌟 核心功能特性

1. **名店 1:1 黃金配方庫（20 款精選特調）**
   - **經典雪頂奶霜系列 (Cremosa)**：經典香草雪頂蘇打 (Torani 風格)、蜜桃厚奶油意式蘇打、覆盆子紅絲絨奶霜蘇打、西西里血橙奶霜蘇打、草莓短蛋糕奶霜蘇打、藍莓黑加侖雪融蘇打。
   - **西西里與意式柑橘系列 (Spritz)**：西西里血橙迷迭香氣泡特飲、阿馬爾菲檸檬冰爽蘇打 (Limoncello 風格)、粉紅葡萄柚海鹽氣泡飲、佛手柑微苦草本氣泡 (Sanbittèr 風格)。
   - **鮮果與野莓清爽系列 (Fruit & Berry)**：電光藍柑夏威夷氣泡、盛夏百香芒芒氣泡特調、綠野青檸薄荷蘇打 (意式無酒精莫吉托)、黑莓晨光漸層氣泡飲、紅寶石石榴氣泡特調。
   - **草本花香與莊園系列 (Botanical)**：法國接骨木花青提氣泡、普羅旺斯薰衣草檸檬蘇打、大馬士革玫瑰荔枝氣泡飲、羅勒西瓜夏日清泉。
   - **0 卡輕享與生酮友好系列 (Zero-Sugar)**：零卡白桃茉莉氣泡水。

2. **智慧氣泡與糖漿泵數計算器 (Smart Calculator)**
   - 支援 **12 oz (355ml) / 16 oz (475ml 標準) / 24 oz (710ml 大杯) / 64 oz (1900ml 派對公杯)** 一鍵精準換算。
   - 標準 1 泵壓頭 = 0.25 oz (7.5ml) 精確換算，支援單風味與雙風味自由拼配（如：覆盆子 3 泵 + 香草 1 泵）。
   - 支援 **無奶純飲 (None) / 微量奶香 (15ml Splash) / 標準 Cremosa (30ml) / 奢華厚雪頂 (45ml)** 奶霜層次調節。
   - 實時精準計算店售價格 vs 自製成本，每杯平均節省 $5.00+，並提供卡路里動態估算。

3. **分步驟調飲倒計時器 & 沉浸式體驗**
   - 整合 Screen Wake Lock API，調飲過程中螢幕保持常亮不休眠。
   - 慢速傾斜 45 度倒水、靜置分層、奶油引流等分步倒計時與蜂鳴音效。
   - 互動式原料清單（點擊劃掉已備原料）。
   - 「我做好了這杯！」一鍵記錄省錢與製作杯數，數據自動持久化保存至本地 LocalStorage。

4. **意式蘇打化學與避坑指南 (Troubleshooting Guide)**
   - **防凝固豆腐腦秘籍 (Curdling)**：酸性糖漿與乳蛋白酪蛋白變性原理，3 種高脂奶油包裹與稀釋方案。
   - **氣泡鎖定持久性 (Fizz Retention)**：冰塊核化點控制、亨利定律低溫溶解度、傾斜 45 度慢注與提拉式攪拌。
   - **雙色/三色漸層美學 (Specific Gravity)**：糖度比重階梯（濃糖漿 > 碎冰物理阻尼 > 氣泡水 > 漂浮鮮奶油）。
   - **商業糖漿 (Torani/Monin) vs 自製新鮮果泥糖漿** 的保存期與糖水比。
   - **氣泡水選型指南**：俱樂部蘇打 (Club Soda) vs 聖培露 (San Pellegrino) vs 家用氣泡水機 (SodaStream)。

5. **100% Amazon Associates 聯盟行銷合規物料店**
   - 所有商品連結採用外部新分頁開啟（`target="_blank"` 與 `rel="noopener noreferrer"`）。
   - 杜絕硬編碼靜態價格（符合 Amazon 政策，僅標註參考市場區間）。
   - 頁面常駐法定免責宣告：*"As an Amazon Associate I earn from qualifying purchases."*。
   - 支援在設定介面一鍵配置與切換自定義的 **Amazon Tracking ID**。

6. **多語系 (i18n) 與深淺主題切換**
   - 支援 **繁體中文 (zh)**、**簡體中文 (zh-Hans)**、**英文 (en)** 一鍵無縫切換。
   - 支援深色模式 (Dark Mode) 與地中海清新淺色模式。

## 🚀 極速本地執行

```bash
# 1. 進入專案目錄
cd "Italian Soda"

# 2. 安裝依賴 (如已安裝可略過)
npm install

# 3. 啟動本地開發伺服器
npm run dev
```

在瀏覽器開啟 `http://localhost:3001` 即可體驗！
